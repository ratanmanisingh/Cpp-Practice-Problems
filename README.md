# Cpp-Practice-Problems

Welcome! 👋

This repository is for practicing **C++ language basics** and **programming fundamentals**. It contains small example programs and practice exercises to help build problem-solving skills step by step.

## What you'll find here

The programs in this repo cover beginner-friendly topics such as:

- Variables and data types
- Input and output
- Conditional statements (`if/else`)
- Multiplication tables
- Recursion (factorial)
- Pattern printing
- Array logic (reverse)
- Functions, function overloading, and parameter passing

## How to use this repository locally

1. **Clone the repository**

   ```bash
   git clone https://github.com/ratanmanisingh/Cpp-Practice-Problems.git
   cd Cpp-Practice-Problems
   ```

2. **Open any `.cpp` file** you want to practice.

3. **Compile with `g++`**

   ```bash
   g++ "Practice Problems/factorial.cpp" -o factorial
   ```

4. **Run the program**

   ```bash
   ./factorial
   ```

> Each `.cpp` file is a **standalone practice program** and can be compiled/run individually.
